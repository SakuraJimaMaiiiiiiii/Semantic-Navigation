# A* 二维规划图

程序每次启动都会在本目录创建一个时间戳子目录，例如：

```text
Visual/20260817_113000_123456/
```

该次任务的全部图片保存在同一子目录中：

- `local_*.png`：去程局部 A*，默认每 2 秒保存一次。
- `return_local_*.png`：返航航段的局部 A*，默认每 2 秒保存一次。
- `global_global_astar_*.png`：全局记忆地图 A* 返航路径。
- `global_recorded_trace_*.png`：全局 A* 无路时的去程轨迹反向返航路径。

保存间隔、分辨率和点数上限在
`astar_2d_visualizer.py` 的 `AStarVisualizationConfig` 中调整。

`local_cell_pixels` 只控制局部图中每个栅格的显示大小，不改变 A* 的
实际地图分辨率；默认每格约 16 像素。

局部图使用与全局图一致的连续鸟瞰栅格样式，不再绘制每个体素的小格线。
黑色为高度过滤后的原始占据体素，橙色为根据这些体素和局部地图相同半径
重新计算的二维膨胀区域；两者都会保存到 `local_*.png` 和
`return_local_*.png`。先过滤高度再膨胀，可防止切片外的天花板障碍只留下
橙色膨胀影子。绘图默认投影机体上方 0.25 m、下方 0.9 m，以聚合更多柱墙
体素。该绘图范围只影响图片，不改变局部 A* 实际使用的碰撞高度范围。

全局图会把稀疏三维体素投影成连续二维鸟瞰占据栅格，再叠加去程轨迹和
返航路径。`global_cell_pixels` 控制全局鸟瞰图中每格的显示大小。

全局 A* 和全局图只保留返航飞行平面附近的体素。高度范围在
`config/planner_config.py` 中配置：`global_return_above_height` 控制机体
上方范围，`global_return_below_height` 控制机体下方范围。NED 坐标的
Down 轴向下为正。默认只取上方 0.25 m，可过滤天花板钢筋；同时从
飞行平面下方 0.9 m 范围聚合多层体素，补全柱子和墙壁轮廓。
下方范围不应大于实际飞行高度，否则地面也会被投影为障碍。
