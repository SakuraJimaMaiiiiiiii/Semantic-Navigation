## 2026-09-28：取消导航自动替代算法

- ego_native 初始化失败或执行异常直接报错，不切换 Python EGO；原生返回无解/轨迹复核不通过时停车。显式 ego 模式仍可选择。
- 删除全局返航 A* 失败后沿记录轨迹直接返航的算法及其专用轨迹抽稀、简化方法。
- 删除任务控制器捕获全局返航异常后改用局部直返的分支。无全局规划器时的显式局部返航入口保留。
- 删除局部 A* 无路时依靠前向深度改为低速直行的分支及其状态标签。
- 删除 sensor_clear_fallback_speed、fallback_min_clearance、fallback_min_map_clearance 和对应校验。

传感器失活、碰撞检测、轨迹碰撞复核、限速/刹停及上层异常悬停/降落处理保留。
此项会使错误更早暴露；不会为了“继续飞”而切换算法，也不保证规划失败后仍能返航。
本次未修改 C++ 源码；已有可用扩展无需重编译，但 ego_native 必须有可用扩展。
FUEL 决策层的 Python fallback 此轮未删除，不应将本次理解为所有备用实现都已移除。
