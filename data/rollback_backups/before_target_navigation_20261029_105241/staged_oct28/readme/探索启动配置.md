# 探索启动配置

从项目目录运行：

```powershell
python run_explore.py
```

默认读取项目内的 `config/explore.json`，不依赖当前工作目录寻找配置。
当前文件选择 SAM3 + FAST-LIO live，等价于之前的
`--sam3 --fastlio live --lidar-scan-model snapshot_assumed`。

- `perception_backend`：`sam3` 或 `yolo_sam2`。
- `fastlio`：`off` 关闭、`record` 录制、`shadow` 实时位姿、`live` 实时位姿与独立点云地图。
- `lidar_scan_model`：`unverified` 未确认；`snapshot_assumed` 实验假设；`snapshot` 仅用于已验证瞬时扫描。FAST-LIO live 仍不接管导航。
- `object_prompts`：`null` 沿用原检测类别，或字符串数组，例如 `["car"]`。
- 其余键对应原探索命令行选项，时间单位秒、距离单位米、面积单位平方米。
- `_comment` 是说明字段；JSON 不支持直接写 `//` 注释。

所有原有启动参数均保留，命令行优先于文件。例如临时使用原感知并关闭 FAST-LIO：

```powershell
python run_explore.py --sam2 --fastlio off
```

对比实验可复制配置文件，然后指定：

```powershell
python run_explore.py --config config/my_experiment.json
```

未知键、错误枚举或类型会在连接仿真前报错，不会静默忽略。
本文件集中的是探索入口全部可选参数；传感器标定、控制器、模型权重等内部配置仍沿用原位置。
