# FAST-LIO 短程闭合验证结果

实验：`run_20261023_190120_712028`。原始输入未修改，完整离线回放完成并正常退出（exit code 0，ikd-Tree 重建线程正常终止）。

## 结论

在明确假设 Type20 为瞬时整帧的条件下，短程数值验证未发现跟踪发散；回到起点后偏差为厘米量级，地图墙体边缘比 PX4 同批点云更集中。但尚不能宣称绝对定位更准或在线导航验证通过。尤其是 LIO 的起终点距离并没有小于 PX4。

## 输入与回放

- IMU：24,884 条；雷达：1,438 帧；recording completed=true、overflow=0、error=null。
- 开头静止检查通过；IMU 严格递增，最大间隔 45 ms；全部扫描在结束时刻之前 30 ms 内有 IMU 样本。
- 7 帧等待静止初始化、1 帧初始化、1 帧建立地图、1,429 帧 tracking；跳过帧数为零。
- 估计器处理耗时中位数 29.51 ms；这不包含文件保存、点云对比和在线应用其他模块的耗时。
- 有效位姿跨度约 183.99 秒。测试任务曾在重复返航微调处超时，但异常清理完成了降落和录制，因此录制仍包含闭合及地面末段。

## 轨迹与闭合

固定使用第一帧匹配位姿进行 SE(3) 对齐，无尺度调整、无全轨迹拟合。PX4 是参考估计，不是地面真值。

| 指标 | 结果 |
|---|---:|
| 全程位置差异 RMSE（LIO vs PX4） | 3.93 cm |
| 差异 P95 | 5.45 cm |
| 最大差异 | 8.31 cm |
| LIO 起终点平均位置距离 | 5.91 cm |
| PX4 起终点平均位置距离 | 3.01 cm |
| 两者闭合位移向量之差 | 4.07 cm |
| 相对旋转变化差异 | 0.40° |

闭合比较用首个有效 LIO 位姿之后 3 秒（25 帧）和记录末尾 1 秒（10 帧）分别求平均；两段均在地面附近。异常返航分支导致最终朝向可能不同，旋转指标比较的是两者估计的相对旋转变化，不要求首尾机头完全相同。未使用仿真真值，物理位置也不能认为精确重合，因此这些数值不是经真值标定的绝对漂移误差。
