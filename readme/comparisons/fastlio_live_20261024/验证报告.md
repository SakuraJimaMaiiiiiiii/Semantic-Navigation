# FAST-LIO 实时建图检查（2026-10-24）

实验：run_20261024_144818_484894。原始实验数据未修改。

结论：同批雷达点云在 FAST-LIO 位姿下，墙线、柱子和车辆轮廓更集中，几何重影明显减少。
不能据此声称绝对定位精度或语义实例关联已改善。

## 方法与数据

使用实时保存的 shadow_poses.jsonl，与 inputs.h5 按完全相等的扫描时间戳匹配；
未重新运行离线估计器。7455 帧 tracking，另有 5 帧静止等待、1 帧初始化、1 帧地图初始化。
两组地图使用相同原始点云、相同 0.1 m 降采样；LIO 只做首帧 SE(3) 对齐，
不拟合整段轨迹、不调整尺度。投影选取 NED z 在 -2.5 至 -0.2 m 的点。

录制完整：175965 IMU 样本，7462 帧雷达，零队列溢出、零估计器报错。
静止初始化通过，IMU 最大间隔 40 ms，扫描结束 IMU 覆盖率 100%。
扫描瞬时性仍只是 snapshot_assumed；接收时钟插值并非硬件同步。

## 对比结果

时长 1364.89 秒（22.75 分钟）。
LIO 与 PX4 位置差异：RMS 10.64 cm，95% 分位 17.64 cm，最大 24.20 cm，末帧 2.34 cm。
这些是两种估计的差异，不是真值误差。

两个有效墙面条带的局部平面残差中位数：
- east_low：PX4 4.59 cm → LIO 0.35 cm。
- east_high：PX4 4.05 cm → LIO 0.40 cm。

约减少 90%–92%，支持点云表面更集中。该指标受采样、选区影响，不代表绝对定位误差；
另外两个自动条带无有效点，未纳入结论。车辆轮廓在对比图中也更清楚，
本轮未量化车辆中心误差或复查实例 ID 正确性。

首末位置距离：PX4 6.97 cm，LIO 9.03 cm。实际首末物理位置未独立验证，
不能当作严格闭环误差，也不能声称 FAST-LIO 返航定位更准。
