# 安全出口门识别与标定

默认启用，无需编译，重新启动 `python run_explore.py` 生效。

- 检测词：exit door、emergency exit door、fire exit door、emergency escape door。
- 统一类别：`exit door`；实例 ID：`exit door_01` 等。
- 与 `exit sign`（安全出口指示牌）、`signboard`（交通指示牌）独立，不跨类别合并。
- 使用现有 SAM2 掩膜、深度与雷达表面支持定位，进入实例关联和语义体素标签流程。
- HTML 显示实例点、包围框和类别；semantic_map.json 与 semantic_graph.json 使用相同 ID。

这是开放词汇模型的视觉预测，并非对门用途的认证。未加入普通 door 提示词，避免把所有普通门都当成安全出口；仍可能漏检或误检，需用实际场景验证。

门的语义标签不代表可以飞穿。占据状态由传感器证据决定，包围框不强制填充障碍；此次不新增开门或穿门行为。
