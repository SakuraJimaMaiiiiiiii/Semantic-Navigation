# 代码与参数清理（2026-11-16）

对项目自有 Python 入口与模块做 AST、导入及调用关系检查，核对共享配置、派生类、回调、测试和离线入口；同时检查 WebSocket 入口语法。第三方依赖、编译产物、模型权重、运行数据和冻结 v3 源码不作为未使用业务代码删除。

清理内容：

- 删除无人调用的旧失败路线过滤模块 `navigation/exploration_failures.py`。当前失败冷却与出发方向恢复仍走实际探索控制器。
- 删除无人调用的 `advance_route` 旧路线推进实现，保留当前 `WaypointCursor`、有效圆角采样和逐段碰撞检查。移除仅测试旧实现及已不存在接口的过期测试，保留当前路径、连续运动与异步航点的回归检查。
- 删除补拍改版后只写不读的 `_reviewed_vehicle_connections`；片段复查由稳定 token、区域数量上限与累计时间预算决定。
- 独立导航配置移除无运行效果的 `timeout`、`max_radius`、`height_step`、`max_height_gain`、`max_viewpoints`、`viewpoint_spacing`、`information_radius`、`frontier_empty_seconds`、`completion_frontier_area`、`coverage_plateau_seconds`、`minimum_map_gain_area`、`return_reserve`、`fastlio`、`lidar_scan_model`，默认 JSON 同步精简。旧文件报出迁移说明，避免静默接受无效配置。探索入口中真正使用的选项继续保留。
- 删除 WildOS 独立导航的两个无用导入，将 CLI 依赖的两个重导出显式声明。

不能因为单个函数未读取某参数就删除协议参数。例如 Python EGO 的直接种子初始化不读取地图和时间，但原生 EGO 派生实现会使用；MAVLink 接收钩子、规划器重验证和 HTTP handler 也具有外部调用协议。离线 HDF5 读取与 PLY 导出保留为独立接口。
