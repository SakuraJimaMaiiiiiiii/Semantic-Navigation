# 返航起点不可通行：高度切层

运行：`run_20261029_111249_517692`。
原报错：`return_start_not_free`，当前位置约 `[-7.789,6.437,-1.439]`。

## 证据

探索终止快照的规划高度为 -1.4623817205429077m；
返航入口重新采样实际 Z，使用 -1.439095139503479m，差约 0.0233m。
返航快照中局部净空体素包含 2 个占据格，全局机身邻域包含 3 个占据格及 2 个未知格。
不能把它们直接删掉。

同一返航快照按不同高度重新投影：

| 规划高度 | 全局起点 | 局部起点 |
| --- | --- | --- |
| -1.439095m，瞬时实测值 | 不可通行 | 不可通行 |
| -1.462382m，探索任务高度 | 可通行 | 可通行 |

附近占据回波包含 z=-1.1m 的局部体素。高度带下边界从约 -1.212m 变成 -1.189m 后，
与 [-1.2,-1.0] 体素层发生正体积重叠。厘米级抖动因此改变了整个投影层集合。

在本次最终保存的完整导航缓存上复算，瞬时高度下起点与原点均不可通行，
探索高度下两端可通行且找到 2 个路径点的路线。缓存与失败快照的采样时间不同，
该结果作为完整路线补充验证，不当作同一时刻的全部地图证据。
统计见 `data/audits/return_height_20261029_111249/comparison.json`。

## 修改

`_return_on_certified_path` 沿用 `nav.altitude`，同时将返航目标 Z、局部规划器高度、
执行上下文高度设为同一任务平面，不再用交接瞬间的实测 Z 另选地图层。
当前位置仍从实时定位读取；小幅高度误差通过既有位置航点控制修正。
实际层内有障碍时仍被拒绝，没有修改体素、障碍距离、未知格策略或落地确认。
探索升高后的返航仍从任务最后使用的平面开始，既有已验证高度恢复逻辑保留。

回归覆盖厘米级高度差、真实体素层切换、返航航点高度一致和任务层内障碍仍拦截。
备份、复算和测试结果保存在上述 audit 目录。无需编译；实飞效果需重启后验证。
