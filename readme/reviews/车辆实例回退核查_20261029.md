# 车辆实例关联与几何融合回退核查

本次仅核查和离线回放，没有修改在线后端、占据建图、FAST-LIO、SAM3或目标导航配置。

## 当前实际入口

`application/demo_runtime.py::_create_processing` 在探索模式注入
`mapping.explore_v3.adapters.SemanticInstanceMapper`。它继承10月20日mapper，
相对导入指向同目录的旧车辆tracker和InstanceSurface。实时检测和在线回环语义重放
均使用这一路旧实例算法。独立目标导航仍使用现代mapper。

旧版没有丢弃所有表面融合：它依然累计多帧支持的表面体素并集。
回退掉的是后续连接车面关联、碎片确认和多车面几何估计。

## 已确认的差异

1. **跨视角连接测量**：现代tracker允许外观一致且覆盖旧稳定车面的测量继续更新旧ID。
   旧版对大面积新车面的支持要求更严格；从车侧转向车头时更容易匹配失败。
2. **局部碎片确认**：现代tracker暂缓把小车角、低矮碎片确认为独立新车，
   并能用重复连接观测融合碎片；旧版缺少这些后续改进。
3. **几何中心**：旧版主要使用累计表面的轴对齐包围框中心。
   现代版对稳定实测表面拟合有朝向的矩形，记录partial_surface / multi_surface_estimate。
   单车面仍不等于整车中心，不补造未观测车面。
4. **补充观测**：旧版adapter只返回已经发布的物体，没有现代版的连接碎片候选，
   因此当前多方位观察模块也收不到这些关联补拍请求。
5. **已有分裂证据**：现代版允许重复且强实测表面重合修正旧的分裂记录；
   同帧独立车辆检测仍阻止合并。旧版的同帧分离记录不能通过这条后续机制修正。
