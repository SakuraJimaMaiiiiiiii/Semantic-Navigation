# 探索低增长复查与柱子识别

## 本次运行证据

`data/runs/run_20261028_140435_896686/exploration/exploration_report.json`
记录结束原因为 `map_expansion_stalled`，探索约 2217 秒，仍有 12 个前沿区域，
`frontiers_exhausted=false`。它并未证明整张地图已经覆盖。

低增长复查从约 1955 秒开始，在约 2078 秒到期。当时地图窗口增长仅 0.09m²。
原来的主循环在复查到期后直接退出，尚未执行 `_coverage_review` 对未访问候选的筛选。
在已知区域中长距离移动、停顿等待时，也会消耗此计时。

## 修改

- 删除主循环中仅凭低增长计时到期就返航的分支。低增长后继续使用现有的候选分批复查，
  排除已到达观察点附近的候选，最多执行现有配置的 3 次补充复查。
- 仍受总时间、观察点数量、半径、失败重试和补充复查预算约束，不会无限延长探索。
- 计时到期状态改为 `review_due`，HTML 和终端显示补充复查，不再误称已经满足返航条件。
- 每轮保存剩余前沿面积，避免结束报告该字段为空。
- `config/explore.json` 增加 `parking garage structural column`。
  现有类别映射把它统一保存为 `column`，使用已有实例关联、HTML 和语义地图导出链路。
  保留多帧可观测高度至少 2.2m、竖直长宽比至少 1.2 的过滤，不启用矮柱。

## 使用与验证

直接重新运行 `python run_explore.py`，不需要 CMake 编译；SAM3 和 YOLO-World+SAM2
均使用同一个默认提示词列表。自行指定其他配置文件时，也需要把柱子提示词加到该文件。

自动测试覆盖复查计时到期后仍可选择未访问区域、补充复查次数上限、后续候选批次，
以及默认柱子提示词经过多帧定位后只发布高柱、不发布矮柱。

12 个剩余前沿不等于 12 个可达区域；本次修正提前退出的决策顺序，不删除障碍或绕过净空检查。
是否提高实际覆盖率，需要下一次 UE 实飞确认。
