# PX4 建图与车辆关联改进（2026-10-10）

VIO 运行入口、专用配置、VINS 原生模块和构建代码已删除。PX4 位姿、雷达占据地图、A*、EGO 和控制器保持原链路。无需重编译，直接 `python run_explore.py`。历史实验数据及通用 IMU 诊断工具保留。

本轮修复针对 05/06 等疑似重复车辆：

- 有稳定表面支持的实例，合并距离采用与地图/HTML 一致的表面包围框中心。滤波状态仍用于观测位置的卡尔曼更新，不将其伪装成整车中心。
- 跨视角观测有外观及包围框、或共同表面支持时，不因滤波观测中心在车头/车尾偏移而在粗筛阶段直接丢弃。
- 合并需要在 2 秒窗口中至少 3 个不同时间戳的支持（使用原确认次数设置）。短暂漏检不添加证据，但也不会立即清空全部证据；过期证据移除。
- 不满足几何/外观条件的新证据、同帧独立物体、多个合并对象竞争仍阻止合并。不会仅凭距离接近合并一排相似车辆。
- 诊断 `confirming` 中的 `supporting_frames` 替代 `consecutive_frames`；记录 `evidence_span_seconds`，同时记录地图中心和滤波中心两种距离。

该更新取代旧文档中“合并必须连续多帧、一次空帧立即中断”的说明。它不保证将未观测到共同区域的两侧车面自动识别为同车，也不修复旧实验的实例标签。下一轮需要重新查看 `maps/vehicle_merge_diagnostics.json` 和车辆图像证据。

最新关联规则：局部车面中心须落在较完整车辆包围框内，并满足高度重叠、面积比例和边界支持条件；允许最多 0.15 m 的边缘容差。仍需外观或共同表面证据，不按距离直接合并。高度不足 0.2 m 或水平最大跨度不足 0.4 m 的车辆观测不创建或更新实例；薄但足够宽高的垂直车面仍可参与关联。

雷达回环检测现已独立接入，详见 [雷达回环检测](雷达回环检测.md)。它只保存几何约束，尚未接入位姿图优化、地图重建和语义坐标联合校正，不能靠检测本身消除漂移。
