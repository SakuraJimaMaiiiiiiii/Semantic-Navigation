# 车辆身份关联与连接视角补拍

适用于后续 `run_explore.py` 和 `run_wildos_explore.py` 探索。两条入口及在线回环回放共用当前 `VehicleInstanceTracker` 和 `ColumnIdentityPolicy`；不使用某次探索的人工编号规则作为自动关联条件。v3 通过适配层采用相同身份决策，保留冻结的占据地图及柱高过滤实现。

## 通用车辆与柱子去重（2026-11-16）

柱子严格入图规则：保留至少 2.2 m 可观测高度，并要求重复支持点形成 0.30–1.60 m 的紧凑水平截面、截面长宽比不超过 2，以及两个非平行方向的竖直面。每个面的有效点至少 24 个、纵向覆盖至少柱高的 65%、横向覆盖至少该面宽的 60%（且不少于 0.30 m）。没有三维表面证据或只有单个平面的高模型分数不能替代这些条件。视频稳定 ID、地图、保存结果和回环输出共用此门槛。

单面候选继续保留内部观测，较高置信度且尺寸合理的候选可请求第二视角；取得第二个面的多帧证据后才正式入图。这会暂时漏掉只拍到一个面的真实柱子，符合严格过滤的取舍；局部墙角仍可能和柱子外观相近，该几何规则不能视为场景真值。阈值针对当前约 1 m 截面的车库柱子。

- 车辆保留局部车面待确认、跨视角关联和连接视角验证。旧 ID 因同帧重复提案被标为独立时，连续新帧中的两块实际观测表面若高度重合，可结合已有共享车面和外观证据自动纠错；真正分离的同色邻车仍禁止合并。
- 柱子同帧重复的三维表面提案先去重，一帧只增加一次正观测。跨视角部分表面可以关联成熟的多面模型，不再要求小块可见面覆盖全部模型的四分之一。
- 柱子历史重复 ID 不再被“曾同帧出现”永久锁住。合并需要三帧新观测共同解释已测表面，或相同横向范围的上下部分被连续竖直表面连接。点云必须处于同一世界坐标，不做 ICP 平移配准，也不因近距离、相似颜色或包围盒重叠单独合并。
- 疑似重复但共同观测不足的柱子输出 `identity_status: needs_connection_view` 与 `connection_targets`，进入与车辆相同的有预算复查。只有局部净空、可达路径和共同可见性均通过才移动；沿用最多两个观察点、45 秒局部预算及全任务截止时间，原始占据证据不会被修改。
- 连接复查按稳定片段标识记忆：已看过一个片段不会阻止另一侧新片段；优先处理尚未复查的片段，时间戳变化或小幅位置变化不重新获得机会。每个对象最多复查两个不同片段，每次最多两个观察点，所有连接复查累计共享 45 秒预算，身份合并后的别名继承已耗时间。确定合并时同步刷新最后有效观测时间，使补拍及时结束。
- 合并后地图、体素标签、语义图及导航旧别名同步使用保留 ID；普通入口、v3 和回环回放采用同一身份逻辑。历史 run 的人工确认文件不参与这些自动决策。

## 先前的局部车面待确认规则

- 同一车辆的前半侧面与后半侧面可能没有点云重叠。外观相容、纵向延伸且高度和横向位置符合单车范围时，先保留待确认片段，不立即发布第二个车辆 ID。这只是同车假设，不能直接融合几何。
- 长侧面和近似方形的端部片段也可能完全没有表面重叠。端部位于侧面的纵向范围内、靠近一端，组合长宽和高度符合单车范围时，同样保留为待确认片段；两种出现顺序及旋转停车方向均适用。相似外观只支持暂缓发布，几何融合仍要求多帧连接视角。
- 同帧出现两个分割框不再足以解除待确认状态。需要多帧、稳定且分离的完整车体证据，才允许发布独立车辆；重复共享车面仍可通过原有连接证据解决同车关系。
- 待确认片段进入实际探索补拍流程。即使主车体已有完整几何，或之前已补拍过，也允许一次有预算的连接视角复查。候选点必须能同时看到主车体和片段，使用已有可达路径、净空检查、半径限制和补拍时间预算；到达后等待多帧新观测。
- 没有共同视角证据时，输出 `identity_status: needs_connection_view` 和 `connection_targets`，地图悬停提示仍待确认，不把假设写成确定的合并。成熟片段跨重访保留，待确认轨迹最多 32 个，各轨迹仍使用有界表面缓存。
