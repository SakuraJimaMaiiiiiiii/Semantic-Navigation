# PX4 与 FAST-LIO 离线对比

实验：`run_20261102_091751_978137`。原始实验数据未修改，导航仍使用现有 PX4 链路。

## 方法与结果

从已保存的 FAST-LIO 输出均匀抽取 300 帧，分别用对应 PX4 和 FAST-LIO 位姿重建同一批雷达扫描。只在首个匹配位姿做刚体对齐，不拟合整条轨迹、不缩放。

| 指标 | 结果 |
| --- | --- |
| 两条轨迹位置差 RMSE | 0.129 m |
| 位置差中位数 / P95 | 0.122 / 0.208 m |
| 最大位置差 | 0.235 m |
| 末端位置差 | 0.043 m |
| 四个外墙条带局部平面残差中位数范围，PX4 | 0.024–0.043 m |
| 四个外墙条带局部平面残差中位数范围，FAST-LIO | 0.0019–0.0048 m |
| 六个车辆区域局部平面残差中位数范围，PX4 | 0.027–0.056 m |
| 六个车辆区域局部平面残差中位数范围，FAST-LIO | 0.0066–0.0162 m |

同一扫描对比中，FAST-LIO 的墙面和车辆区域点云更集中，支持继续将其用于独立建图实验。局部平面残差是表面集中度指标，不是物体中心定位误差。条带和车辆 ROI 可能混有其他表面；两种地图下采样后的点数也不同。

PX4 不是真值，轨迹差不能解释成 FAST-LIO 绝对误差。扫描时序模型仍未验证，在线导航未验证；本次结果不足以批准接管导航或断言车辆绝对定位已经更准确。

## 最新短实验

`run_20261102_101318_188880` 的探索约 53 秒时因车辆补充观察读取空导航请求而中断。该错误已修复并添加探索 `request=None` 的回归用例。其 100 帧抽样轨迹差 RMSE 为 0.047 m，但不能代替完整探索验证。
