# 回环更新与最终保存验证

输入实验：`run_20261102_102916_137270`。未启动无人机或修改原始关键帧、语义观测记录。

## 修改

- 位姿图使用等价的四自由度相对位姿公式和解析雅可比，避免反复构造矩阵、求逆和数值差分。
- 当前与 v3 占据更新使用标量饱和计算，保持更新顺序、阈值、容量和体素证据不变。
- 同一关键帧/约束版本复用几何结果，不因语义日志更新或最终编号重复重建几何。
- 状态文件记录位姿图、占据重建、导航发布、语义导出及 HTML 各阶段耗时，以及已处理/最新关键帧数量。
- 异常关闭时，雷达和语义生产者成功关闭后仍执行最终回环保存，安排在飞行器关闭之后；原始飞行错误仍上报。最终保存成功后不重复执行。

## 验证

- 15 项相关测试通过，含解析导数与数值导数对比、体素饱和等价性、几何缓存、最终保存幂等、落地异常时保存顺序及 v3 后端测试。
- 同一批 54 帧占据重建：原标量 NumPy clipping 7.009 秒，新实现 2.891 秒；体素索引与 log odds 完全相同。详见 `voxel_benchmark.json`。
- 全部 369 帧、154 条回环约束、405 条语义测量离线完成最终导出；最后一次带性能分析及航点显示的运行耗时 26.89 秒，位姿图 4.546 秒、占据重建 18.454 秒、语义与 HTML 3.890 秒。
- HTML 原先仅包含 54 帧，空闲面积 463.5 m²；现在包含 369 帧，空闲面积 1001.25 m²。原始地图空闲面积约 1036 m²，采样重建与原始逐帧积分并不完全等价。

`map_before.html` 保留旧显示。最终地图仍位于原实验的 `exploration/map.html`；回环版本文件位于 `maps/live_loop_corrected`。航点文件没有选择时刻时间戳，本次离线恢复的航点显示沿用无时间戳时使用最后校正变换的现有规则，不能用于验证逐时刻航点坐标精度。

没有把本次落地异常改成成功，也没有启用校正地图导航。离线计时不代表飞行期间 GPU、记录和感知并行运行时的实时耗时；需在下次实验查看新增分阶段计时。
