# 目标导航高度容差死锁核查

实验：run_20261102_192450_871847。四份 failure_001–004 快照均来自同一首段，未修改原始证据。

- 规划高度 -1.501131 m；实际高度偏差分别为 -0.200065、-0.200047、-0.215121、-0.217512 m。
- 局部网格分辨率 0.2 m；NavigationGrid.segment_free 将超过该高度偏差的线段直接拒绝。
- 001/002 在规划后追踪弦段复核处被拒绝；003/004 在规划阶段追踪弦段复核处被拒绝。
- 对四份保存的局部三维 states，以原净空半径 0.35 m、机身半高 0.25 m 检查原地回到规划高度的完整机身体积，全部为已观测空闲。

修改：超出高度容差时，先输出独立的、三维证据验证过的高度恢复段；退出误差为 min(0.05 m, 0.25 × 网格分辨率)，避免阈值附近来回切换。规划和执行前复核均支持该分支。恢复段包含障碍、未知或超出局部地图边界时仍拒绝移动。没有放宽原水平路线净空，也没有将未知格设为空闲。

这解释本轮导航停止的直接原因，不证明实际高度偏移本身的飞控/估计来源。尚未进行新的仿真飞行验证。
