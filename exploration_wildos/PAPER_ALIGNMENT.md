# WildOS 原文对齐说明

依据用户提供的《WildOS: Open Vocabulary Object Search in the Wild》PDF，Algorithm 1–5（第 7–8 页）及 Table 1（第 17 页）。当前默认统一入口采用 paper_aligned 采样并追加实际稀疏连边；恢复 Algorithm 5 全邻域边需加 --dense-edges。以下完整连边结果是稀疏化前基线；这是几何导航图算法对齐，不是整篇系统复现。

## 当前采用的原文规则

| 原文 | 当前实现 |
|---|---|
| Algorithm 1：更新旧节点、采样、更新前沿、连边 | 按这一顺序处理连续快照；保留稳定节点身份与历史 |
| Algorithm 2：自由半径取 obstacle/unknown SDF 与上限的最小值 | 相同公式，使用栅格保守距离下界 |
| Algorithm 2：探索半径取历史值与当前 unknown SDF 的最大值 | 同一存活节点的探索半径不会减小 |
| Algorithm 2：地图范围内自由半径为零则删除节点及边 | 范围内变未知或被占据的节点退役；无人机净空失效也退役 |
| Algorithm 3：从 FreeRegion 均匀独立采样 N 次 | 按自由格均匀选格，再在格内均匀采样连续 XY；固定种子用于复现 |
| Algorithm 3：min(SDFobs,SDFunk) > rtrav | 严格大于 0.5 m，另保留无人机安全格要求 |
| Algorithm 3：只对上一轮 V(t-1) 检查已有自由圆 | 本轮候选不会因其他本轮候选的圆被拒绝；圆可重叠，不强制相切 |
| Algorithm 4：历史前沿仍未知且位于地图范围内则保留 | 保留原归属，不因出现更近节点就重新分配，不要求仍邻接自由格 |
| Algorithm 4：对新边界执行历史探索圆过滤，关联最近无碰撞节点 | 对新前沿应用探索半径过滤，再按距离检查关联；原归属节点被删后可重新检测归属 |
| Algorithm 5：范围内所有节点对，无碰撞则连边 | 空间邻域候选全连接，满足几何与无人机安全约束才输出 |

默认参数：每次 1000 次独立采样；自由半径上限 4 m；连边范围 8 m；采样净空阈值 0.5 m。
不执行额外覆盖补采、低净空优先采样或节点冗余精简。第一帧不沿用旧精简图作为论文采样结果。
10000 个累计节点为工程资源上限，命中时会报告 node_budget_reached；这不是论文参数。

## 保留且明确披露的适配

1. 输入是无人机单高度完整存档快照，原文使用持续更新的局部 traversability map。尚未接入实时探索，也未实现局部窗口之外的完整可规划全局子图。
2. 原图分辨率保持 0.3 m，未把它插值伪装成论文的 0.1 m。距离场扣除单元几何误差；连续采样点进一步扣除到格中心偏移，得到保守下界而非精确连续 SDF。
3. 保留无人机水平净空和竖直高度检查，以及车辆已观测 AABB 约束；这些不是论文 Algorithm 1–5 的车辆节点机制。
4. 已知范围外的历史节点保留为 dormant，但当前快照不能证实安全时不导出为通行节点。未知边界范围以已知格包围盒加一圈未知格表示，不声称这是传感器真实视野范围。
5. 前沿表示未知侧格。关联检查到相邻已知空闲侧的几何视线，未知终点不作为通行路径。论文 CollisionFree 的终端/机器人膨胀细节未由伪代码明确给出，此处是本项目约定，不能标成完全相同。
6. 原文 Algorithm 1 合并历史边；当前快照重验所有候选边，保留有效端点对的稳定边 ID，同时移除穿过新增障碍的旧边。不能为了形式一致而保留已知不安全边。
7. 连续坐标的覆盖统计按实际圆心计算，不再假设节点恰在格中心。原文采样没有全覆盖承诺，黄色未覆盖格会如实保留。
8. 仍未实现 ExploRFM、完整语义评分图、目标辅助节点代价和实际导航控制，不把几何图对齐称作整套 WildOS 复现。

## 使用与切换

```bash
# 默认：论文对齐几何图
python3 -m exploration_wildos --exploration-dir <探索目录>

# 显式回到原覆盖适配采样（参数可从图配置检查）
python3 -m exploration_wildos --exploration-dir <探索目录> --coverage-adapted
```

模式切换会归档旧图和 incremental_state.json，开启新的图状态，不混用两种采样历史。
回放工具的 manifest.options 可显式指定 paper_aligned=true、max_samples=1000、free_radius_cap=4、edge_radius=8、traversability_clearance=0.5、prune_redundant=false、max_nodes=10000。
重复同一快照仍幂等，不重复采样，以免仅刷新页面就改变图。

## 本次真实地图结果

首次论文采样接受 798 个节点，生成 43246 条通行边，1 个连通分量。
10367 个受约束安全格中，10032 个格中心位于自由圆内（96.77%），335 个未覆盖。
这表示圆覆盖率，不等同于已探索比例或图中路径可达区域大小。
所有输出节点、通行边和起点连接通过现有安全与车辆几何复核。
仍有 6 个车辆语义节点、20 个前沿点和 16 个前沿节点。

图较密时页面默认仅显示正在查看节点的邻边，可以切换全部边；仅改变显示，不改变图结构。
切换前的覆盖适配图及状态保存在本次 navigation_graph/history/ 中。

## 后续连边适配

根据用户要求，当前实际输出采用 3 m 内最近 4 邻边 + 连通性补边 + 1.5 倍绕行约束补边。节点采样与前沿规则不变，但不再声称边集合完全等同 Algorithm 5。实际边数和验证见同次运行 navigation_graph/README.md 与 sparsification_comparison.json。

## 后续节点密度适配

当前默认进一步压缩规划节点：保持安全格中心覆盖和连通性、保护前沿/起点，再补回必要路径中间节点。
原采样图和历史仍保留，实际规划图已减少到 222 个节点、647 条边；因此不再把最终点集合称为论文原始采样结果。
查看完整论文候选结构需同时指定 --keep-all-nodes --dense-edges。
